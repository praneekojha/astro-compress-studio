# AstroCompress Studio Pro

A responsive image-compression web app starter. Image processing runs locally in the browser using the Canvas API; images are not uploaded to a server.

## Included
- Responsive dark studio interface
- Image picker and drag-and-drop upload
- Quality slider
- WebP, JPEG and PNG output options
- File-size comparison and download
- No API key or server required for the included compressor

## Run in VS Code
1. Extract `AstroCompress-Studio-Pro.zip`.
2. Open the extracted `AstroCompress-Studio-Pro` folder in VS Code.
3. Open `index.html` in a browser, or install the Live Server extension and choose **Open with Live Server**.

## Notes
- Browser support for output formats can vary.
- PNG output is lossless; the quality slider may not affect PNG encoding.
- Animated GIFs are treated as a still image (first frame).
- This is a client-side starter project, not a hosted website.
